# Subject note — chemistry/physics density

Use only for lessons actually explaining density, **not** as a universal teaching requirement.

- Explain density as **mass per unit volume**; teach an **equal-volume comparison** before using informal shortcuts.
- Density is **not total mass**; comparing objects with different volumes based only on mass is misleading.
- Particle-spacing trends are conditional on material/state/context. Do not teach unconditional spacing statements.
- Ground conditions, units and numerical answers in the actual source; label original teaching examples accordingly.
