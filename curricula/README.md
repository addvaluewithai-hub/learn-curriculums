# هنا المناهج الحقيقية

course-new ينشئ منهجًا، وlesson-new ينشئ درسًا.
المصدر والخطة تحت المنهج؛ بيانات ومكونات وصوت ومراجعة كل درس داخل فولدره.
media/jobs تظهر وقت الإنتاج؛ لا فولدرات فارغة ولا أمثلة وهمية في الفهرس.
المراجع وحدود الوصول تتوثق قبل اعتماد الشرح. لكل منهج جديد: course.json وOUTLINE.md للخريطة العامة، STATUS.md للـBlocks وحالتها، references/SOURCE_MANIFEST.md وSOURCE_COVERAGE.md، وblocks/B01/STATUS.md للجزء النشط. Blocks ليست دروسًا تشغيلية. لا ترفع الكتب المصورة إلى GitHub العام بلا حقوق/إذن؛ اتبع instructions/source-handling.md. PDF الكيمياء القديم غير موجود هنا.
أمثلة الاختبارات في tests، وليست محتوى طالب.
