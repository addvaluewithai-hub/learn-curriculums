## التحقق العددي والرمزي المنفذ هنا

باستخدام SymPy والتبسيط \`factor(together(lhs-rhs))\`، **كل الفروق التالية تساوي صفرًا** عند مجالها المعرّف؛ هذا ليس تدقيقًا بشريًا مستقلاً:

| المثال | الهوية التي اختُبرت | النتيجة |
|---|---|---|
| Example 1، مطبوع ص1 | \((x+1)/(x^2-3x+2)=3/(x-2)-2/(x-1)\) | 0 |
| Example 4، مطبوع ص4 | \((5x+1)/(x^2-x-12)=3/(x-4)+2/(x+3)\) | 0 |
| Example 5، مطبوع ص4–5 | \((x+1)/(x^3+x^2-6x)=-1/(6x)+3/[10(x-2)]-2/[15(x+3)]\) | 0 |
| A-Q0 جديد | \(2/(x-1)+1/(x+2)=(3x+3)/[(x-1)(x+2)]\) | 0 |
| B-Q1 أصيل | \((7x-1)/[(x+1)(x-3)]=2/(x+1)+5/(x-3)\) | 0 |
| B-Q2 أصيل | \((8x-2)/[x(x-1)(x+2)]=1/x+2/(x-1)-3/(x+2)\) | 0 |

كما حُلت معادلات Example 5 من توسع **المقام الصحيح**:
\[
A+B+C=0,\qquad A+3B-2C=1,\qquad -6A=1
\]
وحلها \(A=-1/6,\ B=3/10,\ C=-2/15\). لا يجوز نسب الحل الوسيط المصحح حرفيًا إلى طباعة الكتاب.
