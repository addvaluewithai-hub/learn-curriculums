# B01 — ملاحظات فحص الأصل (Stage 01، ليست Critique تعليمية)

**أصل النص:** العينة المصورة للكتاب *Mathematics I — Algebra*، PDF 3–5 ↔ صفحات مطبوعة 1–5، عينة SHA-256: 7d31b84d27b18b0ada48b7b2849a83aeb0e35784f59bf5db4901b4ffb2fa6f1e.

## شواهد مؤكدة أثناء إعادة الفتح

- **مطبوع ص1 / PDF 3:** Example 1 يقرر (x+1)/(x²−3x+2) = 3/(x−2) − 2/(x−1)؛ بمساواة البسطين الناتج x+1، صحيح جبريًا.
- **مطبوع ص2–3 / PDF 4:** تعريف proper/improper وفق مقارنة الدرجات، وطرق صياغة الكسور للعوامل الخطية المتميزة/المكررة والتربيعية. Example 2 يضع قالبًا فقط.
- **مطبوع ص3 / PDF 4:** **Example 3:** المقام المقروء هو (x+3)(x−2)²، لكن القالب المطبوع أسفله يظهر A/(x+2)+B/(x−5)+C/(x−2)²، وهي عوامل لا تطابق المقام المعلن. القالب الذي يوافق ذلك المقام هو A/(x+3)+B/(x−2)+C/(x−2)². **المسودة تشير إلى أنه قالب محسوب وفق العامل الفعلي، ولا تنسبه للنص الحرفي.**
- **مطبوع ص4 / PDF 5:** Example 4: (5x+1)/(x²−x−12) = 3/(x−4)+2/(x+3)، تأكدت المساواة بتمرير الكسرين لمقام مشترك.
- **مطبوع ص4–5 / PDF 5:** Example 5: (x+1)/(x³+x²−6x) مع x³+x²−6x = x(x−2)(x+3).
- **مطبوع ص5 / PDF 5:** في سطر المقامات بعد الضرب يظهر على **طرف واحد** x(x+2)(x+3) رغم أن التحليل أعلاه والمقام المقابل x(x−2)(x+3). السطر يتعارض مع التحليل الصحيح.
- **مطبوع ص5 / PDF 5:** إحدى هويات البسط المطبوعة تكتب معامل x على صورة A+3B−C بينما سطر معادلة المعاملات لاحقًا يكتب A+3B−2C. التوسع الصحيح هو: (A+B+C)x²+(A+3B−2C)x−6A.
- **مطبوع ص5 / PDF 5:** يظهر في سطر القيم الوسيطة C = −12/15، بينما الصيغة النهائية أسفلها C = −2/15. القيمة التي تحقق الهوية هي **−2/15**، مع A=−1/6 وB=3/10.
